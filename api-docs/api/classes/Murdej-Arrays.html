Recursively fills in missing values in an input array based on a template array.

public static addDefaultsRecursive(array<string|int, mixed> $src, array<string|int, mixed> $defaults) : array<string|int, mixed>

This function iterates through the template array and checks if the corresponding keys exist in the input array. If a key is missing, it is added to the input array with the default value from the template. If both the input and template values for a key are arrays, the function recursively calls itself to merge the nested arrays.

Parameters

The input array to be filled.

$defaults : array<string|int, mixed>

The template array with default values.

The input array with missing values filled in.

renameKeys()

Arrays.php : 135

Renames keys in an array based on a provided mapping.

public static renameKeys(array{: mixed} $arr, array<int|string, int|string> $keys) : array<string|int, mixed>

This method iterates through the $keys array, which defines the renaming rules. For each key-value pair in $keys, where the key is the old key and the value is the new key, it checks if the old key exists in the input array $arr. If it does, the value associated with the old key is copied to a new key in the result array, and the old key is then removed. Keys in the original array that are not present as old keys in the $keys array will remain unchanged in the returned array.

Parameters
$arr : array{: mixed}

The array whose keys need to be renamed.

$keys : array<int|string, int|string>

An associative array where the keys are the old keys to be renamed and the values are the corresponding new keys.

Return values
array<string|int, mixed> —

A new array with the specified keys renamed.
